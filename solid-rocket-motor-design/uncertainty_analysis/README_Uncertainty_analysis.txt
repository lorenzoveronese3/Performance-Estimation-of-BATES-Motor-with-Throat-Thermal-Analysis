README - Verification of the main results of Uncertainty_analysis.m
=====================================================

PURPOSE
-------
This README contains MATLAB copy/paste commands to verify the main results of the script:
- Uncertainty_analysis.m

The script produces:
- Monte Carlo uncertainty analysis.

MATLAB prerequisites
--------------------
- Tested with MATLAB R2025b.
- Statistics and Machine Learning Toolbox for `mvnrnd`.

If `mvnrnd` function is not available in MATLAB, the script cannot be executed without modifications.




1. Verification of Monte Carlo analysis
--------------------------------------------------------

Copy/paste in command window:

```
clear; close all; clc;
diary('MonteCarlo_full_output.txt');
run('Uncertainty_analysis.m');
diary off;
```

This command:
- runs the script generating the Monte Carlo analysis;
- saves the text output in `MonteCarlo_full_output.txt`;
- opens the three figures generated by the script;




2. Monte Carlo table export
---------------------------

We can now run the following code in the command window in order to generate
a summary table of the main results. This table export must be executed after running the command reported in section 1, because it uses variables created by the script.

```
mc_stats = table( ...
    max(pc_max_vector)/1e5, ...
    mean(pc_max_vector)/1e5, ...
    std(pc_max_vector)/1e5, ...
    rel_st_pc, ...
    max(tb_max_vector), ...
    min(tb_max_vector), ...
    mean(tb_max_vector), ...
    std(tb_max_vector), ...
    rel_st_tb, ...
    'VariableNames', { ...
    'Pcmax_max_bar', ...
    'Pcmax_mean_bar', ...
    'Pcmax_std_bar', ...
    'Pcmax_relstd_percent', ...
    'tb_max_s', ...
    'tb_min_s', ...
    'tb_mean_s', ...
    'tb_std_s', ...
    'tb_relstd_percent'});

disp(mc_stats);
writetable(mc_stats,'Montecarlo_results.csv');
```

This generates:
- `Montecarlo_results.csv`;

Uncertainty_analysis graphs explanation

Figure 1 — Convergence of Monte Carlo statistics
This figure shows the cumulative mean and standard deviation of Pc,max and burning time as the number of simulations increases. It is used to verify whether the Monte Carlo results are statistically stable.

Figure 2 — Relative uncertainty convergence
This figure shows the cumulative relative standard deviation of Pc,max and burning time. It expresses the uncertainty of the two main outputs in percentage form.

Figure 3 — Monte Carlo output distribution
This figure shows the values of Pc,max and burning time obtained in each simulation, with a horizontal line indicating the mean value.

Uncertainty_analysis code explanation

The script performs a Monte Carlo uncertainty analysis of the solid rocket motor ballistic behaviour. It starts by defining the nominal motor and propellant parameters, 
including the characteristic velocity c*, the Vieille-law coefficients, the initial chamber pressure, grain dimensions, throat diameter, AP/HTPB mass fractions and propellant density. 
It also defines the standard deviations used to perturb the main uncertain parameters: grain density, grain length and throat diameter.

The central part of the script runs "Ncases" Monte Carlo simulations, with "Ncases = 5000" used as the default value. In each iteration, the burning-rate coefficients `a` and `n` are generated as correlated random variables. The covariance matrix is estimated from the experimental pressure/burning-rate data, while the mean values are based on the nominal coefficients `a_nom` and `n_nom`. 
The grain length, throat diameter and propellant density are perturbed with normally distributed variations. For each perturbed configuration, the code computes the initial burning rate, 
burning surface and mass flow rate, then performs a quasi-steady time integration of the motor burning process.

After all simulations are completed, the script computes the main statistical outputs: maximum, mean, standard deviation and relative standard deviation of the maximum chamber pressure, 
together with maximum, minimum, mean, standard deviation and relative standard deviation of the burning time. These values are printed in the command window.

The final function estimates the uncertainty on the burning-rate law by fitting the experimental pressure and burning-rate data and generating correlated random values 
of a and n for each simulation.
