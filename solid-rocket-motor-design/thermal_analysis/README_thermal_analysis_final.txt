================================================================================
README - Verification of the main results of thermal_analysis_final.m
================================================================================

PURPOSE
-------
This README contains MATLAB copy/paste commands to verify the main results of:
  - thermal_analysis_final.m

The script produces:
  - Nozzle geometry and channel geometry (Strategy A: variable channel width);
  - Gas thermodynamic state along the nozzle from NASA CEA interpolation;
  - Hot-gas-side and coolant-side HTC profiles, Bartz sigma factor, fin efficiency;
  - Wall heat flux (convective + radiative) and temperature stack (all layers);
  - Four safety checks: cavitation, ONB (Bergles-Rohsenow), CHF (Zuber + FC), Von Mises;
  - N2 pressurant bottle and water tank sizing;
  - Parametric sweeps: TBC thickness, coolant mass flow rate, number of channels;
  - TBC vs no-TBC comparison.
  - 12 figures (Section S9).

MATLAB prerequisites
--------------------
  - MATLAB R2025b or GNU Octave 11.1.x.
  - No additional toolboxes required.


1. Run the script and save the full output
-----------------------------------------------------------------

Copy/paste in command window:

```
clear; close all; clc;
diary('thermal_analysis_final_output.txt');
run('thermal_analysis_final.m');
diary off;
```

This command:
  - runs the full script (geometry, solver, all safety checks, all sweeps);
  - saves the complete console output to  thermal_analysis_final_output.txt;
  - opens the 12 figures generated by the script (Section S9).

All key results (temperatures, heat flux, safety margins, feed system sizing,
parametric sweep tables) are printed directly to the console during execution
and are fully captured in the diary file.

Expected run time: approximately 15-25 s on a modern laptop.

================================================================================


Code structure
-----------------------------------------------------------------

The script is divided into nine clearly labelled sections (S1–S9) that follow
a strict data-flow order: no section reads data that has not yet been computed.

  S1 — Pure scalar inputs
       All numerical parameters defined as plain assignments with no formulas.
       Every value carries a source tag: [ASSIGN] (assignment spec), [CEA]
       (NASA CEA2 output), [LIT] (peer-reviewed literature), or [DESIGN]
       (engineering choice justified in the report). Sub-groups cover combustion
       gas properties, engine spec, nozzle geometry, thermal protection stack
       (YSZ TBC, NiCoCrAlY bond coat, CuCrZr liner), cooling channel geometry,
       coolant conditions, external hydraulic circuit, CuCrZr mechanical
       properties, radiation parameters, solver control, and N2 feed system.

  S2 — Derived scalar quantities
       Standard gravity, gas constants, propellant mass flow rate, burn time,
       throat area At and radius Rt, thermal resistances per unit area,
       per-channel mass flow, and inlet water properties from IAPWS-IF97.

  S3 — Axial grid and nozzle profile
       1-D spatial discretisation of the conical nozzle. The axis runs from
       x = -L_conv (subsonic AR = 2, jacket inlet) to x = +L_div (supersonic
       AR = 2, jacket outlet), throat at x = 0. Outputs: x, r(x), AR(x),
       arc-length element ds, inter-node average radius r_avg.

  S4 — Gas thermodynamic and transport properties
       Linear interpolation of NASA CEA tables onto the axial grid. Convergent
       nodes use the shifting-equilibrium branch; divergent nodes use the
       frozen-composition branch. Computes Mach number M(x), static temperature
       T_s, static pressure p_s, gamma, Cp, mu, Pr, speed of sound, turbulent
       recovery factor r_rec = Pr^(1/3), and adiabatic wall temperature T_aw.

  S5 — Cooling channel geometry (variable-width Strategy A)
       Channel pitch = C_wall(x)/Nch; width w_ch(x) = pitch - t_fin (fin
       thickness constant). Computes cross-section area A_ch, three-sided
       wetted perimeter P_wet, hydraulic diameter Dh, and aspect ratio AR_ch
       at every node.

  S6 — External feedline pressure losses
       Distributed friction (Haaland explicit factor) and concentrated losses
       (K-factors: valve, orifice, elbows, filter) in the supply line.
       Sets coolant inlet pressure p_inlet for the marching solver.

  S7 — 1-D axial marching thermal solver
       Calls the local function marching_solver(). At each node: updates
       coolant static pressure (forward-Euler friction), evaluates IAPWS-IF97
       water properties, runs a fixed-point loop on T_hg and T_wc coupling the
       Bartz (1957) hot-gas HTC, Gnielinski (1976) coolant Nu with Shah &
       London (1978) aspect-ratio correction, fin efficiency (Incropera), and
       gas-band radiation. Advances coolant enthalpy to the next node.

  S8 — Post-processing: safety checks and feed system sizing
         S8a: cavitation check — p_static > SF_cav * p_vap(T_w) at every node.
         S8b: ONB check — Bergles-Rohsenow (1964) L1 (subcooling) and L2
              (superheat threshold) criteria.
         S8c: CHF check — Zuber (1958) pool bound (informative) and Celata
              forced-convection enhancement (design criterion, SF_req = 1.5).
         S8d: mechanical stress — Von Mises criterion on the CuCrZr liner
              (membrane + bending + thermal stress, temperature-degraded yield).
         S8e: N2 blow-down sizing — adiabatic model (design) vs isothermal
              (lower bound), water tank volume and total water mass.
         S8.5: TBC thickness parametric sweep (0–250 µm, 30 points).
         S8.6: coolant mass flow rate sensitivity (2–12 kg/s, 20 points).
         S8.7: number of channels Nch sensitivity ({60,90,120,150,180}).
         S8.8: TBC vs no-TBC comparison — quantifies TBC necessity.

  S9 — Figures
       Produces 12 figures covering nozzle and channel geometry, CEA gas state,
       HTC and fin efficiency profiles, wall heat flux, temperature stack across
       all layers, four safety margin profiles, TBC parametric sweep, mass flow
       sensitivity, TBC vs no-TBC comparison, coolant bulk temperature, radial
       temperature profile at the throat, and N2 blow-down pressure history.
